# Set up Isolinear Memory with an agent

Select the Markdown folder you want to use, then give this prompt to an agent
with authorized access to that folder.

```text
Set up or update Isolinear Memory in the Markdown folder I selected.

Use the setup-isolinear-memory skill if installed. Otherwise, follow the installation
guide for the release you choose:
https://github.com/Kian-hdr/isolinear-memory/blob/v0.7.2/docs/INSTALL.md

Check the existing AGENTS.md, INDEX.md, project format and local binding first.
Verify all downloaded assets against the release's external SHA256SUMS before use.
Keep existing instructions, layout, project identity, history, provider and access
grants. For an empty folder, choose the team, personal or project profile that fits
my purpose. Ask for the exact folder only if it cannot be determined safely.

Verify the installed version and local capture in the selected folder. Report the
profile, what you created or reused, and any unresolved local check. Leave cloud
upload queues alone unless I requested a delivery check.
```
